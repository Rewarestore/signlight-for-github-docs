Privacy policy

Signlight for GitHub is a GitHub Action published under the Reware Apps brand and operated by Reware ApS. It runs in the installing repository's GitHub Actions environment and does not call a Reware Apps service.

Data used

The Action reads pull request and issue-comment event metadata, the current HEAD SHA, actor login, repository permission and an optional signer allowlist. It uses the caller-provided ephemeral GITHUB_TOKEN to update the repository.

Data stored

A bot-authored pull request comment stores the signer login, UTC timestamp, signed SHA, revocation state, processed event IDs and up to 100 history entries. A GitHub commit status stores the red, green or yellow result. Reware Apps receives or stores none of this data.

Control and deletion

Repository administrators control workflows, logs, comments and retention in GitHub. Removing the workflow and deleting the Signlight state comment removes the app's repository state.

Questions

For privacy questions, email Reware Apps. Do not send repository secrets or tokens.
