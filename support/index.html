Signlight for GitHub

Support

For workflow help, email Reware Apps support with the public run URL or a redacted error description.

Commands and states

  • Red: unsigned or revoked.
  • Green: signed SHA equals the current PR HEAD.
  • Yellow: new commits made the sign-off stale.

Authorized users sign with /signlight sign. The active signer revokes with /signlight revoke.

Safe workflow setup

Use the documented minimal permissions. Signlight never needs to check out or execute pull-request code in a pull_request_target workflow.

Scope

Best-effort support has no contractual SLA. Signlight complements—never replaces—GitHub branch protection and required reviews.
