Commit-bound PR sign-off

Keep business sign-off attached to the exact pull request commit.

Signlight adds a separate PR status for release or business approval. Green matches the current HEAD commit. Yellow means new commits arrived. Red means there is no active sign-off.

Native to GitHub

A tiny layer beside code review.

Required reviews remain the right tool for code approval. Signlight adds one explicit, visible business or release acknowledgement bound to the PR HEAD SHA.

Bind the exact version

The immutable 40-character pull request HEAD SHA is the signed version.

Use GitHub identity

Authorized maintainers sign with a PR comment, and only the active signer can revoke.

Spot later edits

A synchronize event turns the previous green status yellow when the HEAD SHA changes.

No Signlight service

GitHub runs the workflow.

The Action uses the repository's ephemeral GITHUB_TOKEN, commit statuses and one bounded bot-authored state comment. There is no Reware backend, database, account or checkout.

Free Marketplace candidate

Make release sign-off unambiguous.

Signlight for GitHub is being prepared as a free public Action. It is not a replacement for required reviews, a legal e-signature or a compliance control.
